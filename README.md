# ⏰ Flutter Clock App UI

A simple and responsive Flutter Clock application UI built using basic Flutter widgets and layout components.

This project demonstrates:

* Scaffold & AppBar
* Digital and analog clock display design
* ListView and custom widget composition
* Custom UI using Container, Row, Column, and Canvas
* Dark mode theme switching
* Navigation between clock types
* Responsive Flutter layout
* Clean and beginner-friendly Flutter structure

---

## 📱 Features

✅ Digital Clock Display

✅ Analog Clock Display with Custom Painter

✅ Clock Type Switching using Bottom Navigation

✅ Dark Mode Support

✅ Real-time Time Updates

✅ Responsive Design

✅ Custom Clock Widget UI

✅ Theme Toggle Switch in AppBar

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/KAHimel/Clock-App.git
```

### 2. Navigate to project folder

```bash
cd Clock-App
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```

## 🎯 Project Objective

This project is built as a clean Flutter UI demonstration for displaying real-time clock information with multiple display formats.

### Requirements Completed

* Implemented a responsive clock UI with multiple display options.
* Used required Flutter widgets:
  * Scaffold
  * AppBar
  * BottomNavigationBar
  * Container
  * Row
  * Column
  * Switch
  * Text
  * Icon
  * Custom Paint widgets
* Created reusable clock display components.
* Built dark mode and light mode theme support.
* Implemented digital clock screen with real-time updates.
* Implemented analog clock screen with custom painter.
* UI-responsive implementation with clean navigation between clock types.
